# Supermarket Sales Analysis

Business Analytics project using Microsoft Excel.

## About the Project

This project analyzes supermarket transaction data to understand sales performance, product-line performance, customer characteristics, and key statistical relationships.

The analysis was performed using Excel, PivotTables, statistical functions, and data visualization, followed by the development of a dashboard.

## Key Highlights

- 1,000 transaction records analyzed
- 5,510 total items sold
- 322,966.75 total sales
- Food and Beverages recorded the highest total sales
- Health and Beauty recorded the lowest quantity sold
- Correlation analysis was performed on key variables
